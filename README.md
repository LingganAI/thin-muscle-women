# 薄肌女生版（thin-muscle-women）

> **English version：** [SKILL.en.md](./SKILL.en.md) · [README.en.md](./README.en.md) · 可直接安装的英文目录 [en/](./en)

一个 AI 私教 Skill，面向女性的轻力量训练。**它不改你的体重，它改你 60 岁还能不能自己站起来。**

市面上流传的「薄肌圣经」是男性版。这一份把它改写成女性版本——不是换个封面，是三处硬改：

| | 男版 | 女版（本 Skill） |
|---|---|---|
| 部位优先级 | 肩 > 背 > 腹 > 胸 > 腿 | **下肢 > 核心 > 背 > 上肢** |
| 体脂目标 | 冲 10–13% | **守住 20–23%**（低于 17% 有闭经风险） |
| 补剂 | 通用建议 | **肌酸储备比男性低 70–80%**，剂量单独算 |
| 生理 | 不处理 | 经期 / 产后 / 盆底 / 骨密度各有硬红线 |

## 装它

Skill 是**一个文件**，没有依赖，没有 API key。

```bash
# WorkBuddy / CodeBuddy
mkdir -p ~/.workbuddy/skills/thin-muscle-women
curl -L -o ~/.workbuddy/skills/thin-muscle-women/SKILL.md \
  https://raw.githubusercontent.com/LingganAI/thin-muscle-women/main/SKILL.md
```

或者直接 clone 整个仓库：

```bash
git clone https://github.com/LingganAI/thin-muscle-women.git
cp thin-muscle-women/SKILL.md ~/.workbuddy/skills/thin-muscle-women/SKILL.md
```

装完重启对话即可生效。

## 怎么用

它不是一个问答机。你开口问一句，它会**反过来接管对话**，先把你的档案问清楚（年龄、身高体重、器械、训练史、经期情况、目标），再出计划。之后每次练完跟它说一句，它负责记录、对比、加码。

随便怎么开口都行：

> 我想练薄肌，但怕练粗。

> 我只有一对 2kg 哑铃，能不能练？

> 今天吃了这些（附照片），帮我算下蛋白质够不够。

> 经期第二天，今天还要不要练？

> 上周深蹲 3×12，这周该怎么加？

它会做的几件事：

- **纠正目标**——先告诉你薄肌不是瘦，是有肌肉量且体脂够低，体重秤是错的度量
- **用你自己有的东西排计划**——只有 2kg 哑铃、弹力带、自重也能排，靠自重六旋钮（次数 / 节奏 / 杠杆 / 幅度 / 停顿 / 组数）做渐进超负荷
- **盯住渐进超负荷**——这是全系统唯一不可妥协的原则，每次都要比上次多一个或多一秒
- **记录你的数字，每周跟你算账**——围度和力量，不谈体重
- **按经期症状微调，不硬排周期化课表**（证据不支持通用周期化）
- **吃东西时也管**——热量、蛋白质、肌酸、维 D、钙、铁，一句话给数
- **给你情绪价值**——夸你夸到具体处，不叫姐妹不叫宝宝

## 这套东西的依据

不是我编的。写在 Skill 第三章里，随时可以查：

- **《女性肌肉力量训练图解》**（法）弗雷德里克·德拉维尔 著，李斯吟 译，山东科学技术出版社 2025，ISBN 978-7-5723-2420-8
- **《ROAR》** Stacy Sims 著——女性运动营养与生理，蛋白质 1.8–2.2 g/kg 的出处
- **《运动营养学（第三版）》** 高等教育出版社 2022，ISBN 978-7-04-058335-9
- **ACSM 2026 立场声明**——每周 1–2 次 × 2–3 个动作 × 1–3 组即可有效；骨密度处方
- **李若彤方法论**——34 岁起步、硬拉 20kg、3:2:1 饮食、她自己踩过的三个坑

关于月经周期是否要周期化训练，两份权威意见不一致（ROAR 支持周期同步，RCT 证据不支持通用周期化）。Skill 里把这个分歧摊开讲，取折中方案：**按症状微调，卵泡期冲、黄体期降**。

## 附赠：可打印训练卡

- `training-card.html` — A4 四页版，含档案条、三天分化、动作阶梯、围度记录表。用 Chrome 打开 → 打印 → 存为 PDF
- `wallpaper.html` — 1080×1920 手机壁纸版，截图即可设成锁屏

卡片里留了填空下划线，打印后手写你自己的数字。默认节奏是**一周三次（周一 / 三 / 五），每次 30–40 分钟**。
